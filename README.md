# Township Urban Development

**市長とAI都市計画局が進める、Townshipの都市開発記録。**

施設配置の相談から始まり、用途地域、工区、Sprint、施工、レビューという進め方が自然発生した。ここでは街の完成形だけでなく、計画が変わっていく過程も残す。

> 移転による成長ではなく、増設による成長。

## このリポジトリについて

Townshipのゲームデータやソースコードは管理しない。都市計画、整備判断、スクリーンショット、活動日誌をMarkdownと画像で記録する。

都市全景のAI生成画像は**構想を俯瞰するイメージ図**であり、ゲーム内の正確な配置図ではない。建物の位置確認には実際のスクリーンショットを用いる。
