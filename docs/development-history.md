# 都市開発履歴

このファイルは**何を整備したか**をSprint単位で蓄積する。会話の展開や発想は[活動日誌](episodes/2026-11-21.md)に記す。

## Sprint 1 — 都市の基盤・用途整理

**記録上の到達点**

- 農業・畜産、農畜産加工、食品製造、一般工業、鉱工業という産業分類を整理。
- 山際、鉱山周辺、貨物線沿い、市街地、海側の用途分担を検討。
- 食品加工地区の配置を検討し、ジャム工場などの移転は地区全体の配置を確認してから進める方針に。
- 既存地区を繰り返し移転させず、増設で街を成長させる原則を明確化。

**注意**：この項目は初期都市計画の到達点をまとめたもの。個々の施工完了日やSprint 1の厳密な範囲は未確認。

## Sprint 2 — 貨物駅周辺産業地区

**確認できる整備・検討内容**

- 貨物線沿いの一般工業・物流地区の配置を整理。
- 産業道路を整備し、中央分離帯に花壇・植栽を配置。
- 工場配置を調整し、赤レンガの産業アカデミーなどの位置関係を見直した。
- 空港側との緩衝緑地や将来の開発用地を意識した計画を検討。
- 整備完了をSprintの区切りとして扱う発想が生まれた。
