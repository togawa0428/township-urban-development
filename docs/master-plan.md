# 都市基本計画

## 基本原則

**移転による成長ではなく、増設による成長。** 既に整えた地区を成長のたびに大移動させるのではなく、地区ごとの役割を明確にし、将来用地を残しながら拡張する。

## 土地利用の骨格

| エリア | 主な用途 | 計画上の考え方 |
|---|---|---|
| 山際 | 農業・畜産、飼料工場 | 農業系機能を集約する |
| 鉱山付近 | 鉱工業、製錬・資源施設 | 資源採掘との位置関係を重視する |
| 農業と工業の中間 | 農畜産加工・食品製造 | 原料から製造へのつながりを意識する |
| 貨物線沿い | 物流・一般工業 | 貨物駅周辺の産業集積と道路を整える |
| 市街地中央 | 公共・商業・文化 | 街の中心機能を配置する |
| 海側 | 住宅 | ゆとりのある住環境を目指す |
| 海岸 | 観光・レジャー・公園 | 景観と余暇機能を重視する |

## 整備判断の原則

1. 個別の建物を動かす前に、地区全体の配置と移転先を検討する。
2. 道路・緑地・景観を施設配置と一体で考える。
3. 将来の増設に必要な空き地を残す。
4. 計画図と実際の施工可能性を区別する。
5. 完了した整備はスクリーンショットと開発履歴に残す。

## 留意点

本書は会話・録画から復元した計画の要約。厳密なゲーム座標、全施設の確定配置、未着手区画の境界は記録から確定できない。
